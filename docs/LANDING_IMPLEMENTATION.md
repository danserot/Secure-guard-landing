## Состав

`frontend/src/landing/LandingPage.tsx` собирает страницу; `content.ts` содержит
сценарии, преимущества и FAQ; `EventDemo.tsx` — переиспользуемый макет карточки;
`LeadForm.tsx` — форма; `landing.css` — стили публичной страницы.

`main.tsx` выбирает публичную страницу для `/landing` и `/landing/` до загрузки
панели и её providers. Остальные маршруты используют исходное приложение.
Сравнение SHA-256 существующих файлов `src` с источником показало, что из старых
файлов изменён только `main.tsx`. Файлы `App.tsx`, авторизация, repositories,
виджеты панели и localDatabase перенесены без изменений. Это подтверждает
сохранение кода, но не является проверкой рабочей БД или production-сессии.

Макет следует структуре исходной панели: магазин/касса/время, причина,
видеоконтекст, POS-события, решения «Подтвердить», «Ложная тревога», «Не уверен».
Он не обращается к API событий и не меняет рабочие данные. Использована
оптимизированная иллюстрация `camera-preview.png` из исходного frontend.

## Проверено локально

- `npm run build`: TypeScript и production-сборка прошли.
- `npm run lint`: ESLint прошёл.
- Полный набор Vitest: 17 файлов, 46 тестов прошли до последней доработки текстов
  сетевых ошибок. После этой доработки повторно прошли все 7 тестов формы
  (5 прежних и 2 новых); сборка и линтер повторены.
- Chrome через Playwright CLI: 360, 390, 768 и 1440 px, без горизонтального
  скролла; изображения загружены. Скриншоты в `output/playwright/`.
- Смена сценария обновляет причину и POS; решение объявляется через live region
  и сбрасывается при смене сценария; временная шкала обновляет время макета.
- FAQ открывается и закрывается; основная CTA ведёт к форме. Мобильное меню
  ведёт к пилоту, закрывается после перехода и клавишей Escape из навигации.
- На 390×844 основная CTA находится на первом экране.
- Некорректный контакт блокирует запрос. При незаданном endpoint браузер
  показывает «Данные не отправлены» и не выполняет POST.
- Скачан UTF-8 TXT с введёнными тестовыми данными и явной пометкой, что это
  не отправленная заявка. Файл проверен чтением.
- `prefers-reduced-motion: reduce` отключает smooth scrolling.
- Production preview на отдельном порту: `/landing` и `/landing/` открываются;
  `/` и `/incidents` без токена показывают прежний экран входа. Полный вход
  с backend и доступ к реальным данным не проверялись.
- В production загрузка `/landing` не запрашивает chunks `App`, `AppProviders`
  и `Webcam`. PNG Open Graph доступен, title/description прочитаны из DOM.
  Первая клавиша Tab показывает ссылку пропуска с видимым outline.
  JavaScript page errors при этих переходах не зафиксированы.
- Тесты формы проверяют состояния ожидания и успеха с номером, отсутствие
  приёмника, невалидный контакт, отсутствие квитанции, HTTP 503, HTML fallback
  и сетевую ошибку. Успех в тестах использует подменённый ответ, не живой backend.
