Таблица: https://docs.google.com/spreadsheets/d/1amKkW7EBxeKOEnczDO7fFy7pA6LP2uzhXd9BPCJeec4/edit

Лист **Заявки**, диапазон **A:K**. Не переименовывайте заголовки и не меняйте порядок
столбцов: обработчик сверяет их перед записью. Статус и комментарий можно менять вручную.

| Столбец | Значение |
| --- | --- |
| A | Дата и время, часовой пояс Asia/Qyzylorda |
| B | Номер заявки UUID, защита от повторной записи |
| C | Имя |
| D | Телефон или email, текстовый формат |
| E | Город |
| F | Количество касс |
| G | Оборудование и вопрос посетителя |
| H | Статус, первоначально «Новая» |
| I | Комментарий команды |

## Обработчик Google

Код: `integrations/google-sheets/Code.gs`. Он выполняется на стороне Google,
поэтому отдельный backend для этой интеграции не требуется.
Проект Apps Script: https://script.google.com/u/0/home/projects/1K-sIAhOVx-4iizFSgp_s6w6HSlnXJMMcShvunBK2IPtm-QG9V2Tg4dbU/edit

Опубликованный обработчик:
https://script.google.com/macros/s/AKfycbyq8P8IQFhkIOrsSdwX-epalMhdGnl_6xcRJ0evQL5wQ83S2r4PWk9Ei8yWigAyJ7UCKw/exec

Публикация проверена: выполнение **от имени владельца**, доступ **Все**.

1. В таблице: **Расширения → Apps Script**. Вставьте `Code.gs` в основной файл.
2. Сохраните код. При необходимости перенесите настройки из `appsscript.json`.
3. **Начать развёртывание → Новое развёртывание → Веб-приложение**.
4. Выполнение: **От моего имени**. Доступ: **Все**, если заявки должны приниматься
   без входа посетителей в Google. Это отдельный доступ к обработчику; доступ к самой
   таблице он не изменяет. Владелец подтверждает запрошенные Google разрешения.
5. Скопируйте выданный URL `https://script.google.com/macros/s/.../exec`.

Этот обработчик открывает только заданную в коде таблицу, но разрешение OAuth
`spreadsheets` технически предоставляет скрипту работу с Google Таблицами аккаунта.
Веб-приложение предоставляет только запись заявки; GET возвращает название сервиса
и версию, без строк таблицы. Публичный адрес не является секретом или защитой от спама.

## Настройка сайта

Адрес для сборки уже записан в `frontend/.env.production` (только публичная настройка,
без ключей и токенов). Для локального dev он также записан в `frontend/.env.local`.
При смене обработчика замените `VITE_LEAD_ENDPOINT` в обоих файлах:

```dotenv
VITE_LEAD_ENDPOINT=https://script.google.com/macros/s/ВАШ_ID_РАЗВЕРТЫВАНИЯ/exec
```

Перезапустите Vite. При публикации задайте эту же переменную в окружении сборки
хостинга и пересоберите сайт (`npm run build`). Не используйте URL редактора или `/dev`.

Для Apps Script форма передаёт JSON с `Content-Type: text/plain;charset=utf-8`,
чтобы не вызывать CORS preflight, и не передаёт cookies Google. Успех показывается
только после читаемого JSON `{accepted: true, requestId: "..."}`. Режим `no-cors`
не используется: непрозрачный ответ нельзя считать подтверждением записи.
Для `/api/leads` сохраняется обычный `application/json`.

## Повторы и ограничения

- При повторе неизменённой анкеты в открытой странице сохраняется тот же UUID.
  Уже записанный UUID возвращает прежнюю квитанцию без второй строки.
- При изменении анкеты создаётся новый UUID. После перезагрузки страницы UUID также
  будет новым; после неоднозначного сбоя сначала проверьте наличие заявки в таблице.
- Сервер проверяет обязательные поля, типы, длины, контакт, количество касс и согласие.
  Формулы из пользовательского текста экранируются.
- Блокировка сериализует запись. Постоянные PropertiesService-квоты ограничивают
  валидные запросы: 30/мин, 300/час, 1000/сутки до открытия таблицы. Кэш хранит
  только квитанции и не используется как источник квот.
- На нормализованный контакт допускается три новые заявки/час, таблица ограничена
  10 000 заявок без автоматического удаления. Это базовая защита, не CAPTCHA.
- При `RATE_LIMIT` и `BUSY` форма соблюдает `retryAfter`; параллельная отправка заблокирована.
  Полные значения и ограничения защиты: [SECURITY.md](SECURITY.md).
- Сервис зависит от квот и доступности Google Apps Script. Автоматических повторов нет.
- По выбору пользователя доступ к таблице по ссылке сохранён.

Живая проверка из браузера Edge на `http://127.0.0.1:5175/landing#contact` прошла:
в 11:51 (Asia/Qyzylorda) тестовая анкета получила подтверждение

а не обращением клиента.

До завершения разрешений Google адрес показывал `Authorization needed`: первая
отправка вернула ошибку и не добавила строку. После подтверждения разрешений
повтор той же анкеты получил читаемый JSON и отобразил номер заявки.
Для опубликованного домена сайта контрольную отправку нужно повторить после деплоя.

```powershell
npm run test:sheets
npm --prefix frontend test -- src/landing/LeadForm.test.tsx
npm run build
```

Локальные тесты проверяют контракт и обработку ошибок на подменённых сервисах.
Живое подключение считается проверенным только после отправки тестовой формы
в браузере и чтения соответствующей строки в Google Sheets.

После изменения кода Apps Script обновите развёртывание на новую версию через
**Управление развёртываниями → Изменить → Новая версия**. Простого сохранения кода
недостаточно для обновления опубликованного `/exec`.
